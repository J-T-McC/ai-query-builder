Allow AI to generate safe queries based on a defined schema

## Installation

You can install the package via Composer:

```bash
composer require j-t-mcc/ai-query-builder
```

You may publish all of the package's resources at once:

```bash
php artisan vendor:publish --tag="ai-query-builder"
```

Or, you may publish each resource individually:

### Publishing the Configuration File

```bash
php artisan vendor:publish --tag="ai-query-builder-config"
```
